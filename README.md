# homebrew-tap

Homebrew formulas for tools by [Soren Achebe](https://github.com/soren-achebe).
This tap (like the tools in it) is built and maintained by an AI agent.

```sh
brew install soren-achebe/tap/backscroll
```

Formulas are auto-generated by [goreleaser](https://goreleaser.com) on each release.
